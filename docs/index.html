Set up a mobile POC in minutes

One command builds all the Contentsquare projects your mobile POC/POT needs — and switches on everything you need to demo the SDK. No more clicking through Console.

⬇  Download the tool · macOS (Apple Silicon) Latest version, always. See all releases.

What it does for you

Setting up a mobile POC by hand means creating the Console projects yourself and remembering to flip on a long list of settings. Miss one and that feature just won't show up in your demo. This tool does all of it for you:

  • Creates the right projects — iOS, Android, and/or webview — based on what's in the Disco.
  • Turns on everything you need to show off the SDK: Session Replay, Heatmaps, Crash Reporting, API & webview error tracking, and more.
  • Sets capture and Session Replay recording to 100%, so data appears in your demo right away.
  • Hands you the project links and copy-paste setup instructions to give straight to the client's dev team.

No guessing, nothing forgotten. Setup goes from an afternoon to a couple of minutes.

1Download & open it

It's a single file — nothing to install. Download it above, then open Terminal, go to the download folder, and paste these three lines (the first tells macOS to trust it; the others make it runnable and available everywhere):

xattr -c csq-xp-setup
chmod +x csq-xp-setup
sudo mv csq-xp-setup /usr/local/bin/
"Apple could not verify…"? That's macOS blocking an unsigned download — click Done (not "Move to Bin"). The xattr -c line above is the fix: it clears the download quarantine so the tool runs. (GUI alternative: System Settings → Privacy & Security → Open Anyway.) The tool also quietly updates itself: if a newer version is out, it'll tell you on startup.

2Get your login token (one time)

The tool logs in to Console as you, so the first time you run it you paste in a token. After that it remembers you and refreshes itself — you won't need to do this again for about a week.

Quick version:

  • Log in to Console in Chrome like you normally would.
  • Open Chrome's developer tools (⌥ Option + ⌘ Command + I) and click the Network tab.
  • Type webapi in the filter box, then click around Console so something shows up in the list.
  • Click any item, find the line starting with Authorization: Bearer, and copy the long code after the word Bearer (it starts with eyJ).
You only do this occasionally. The tool keeps your login fresh in the background. You may get a one-time macOS Keychain pop-up — just click Always Allow.

3Run it

In Terminal, run this with your deal name and the token from step 2:

csq-xp-setup --deal "Acme Corp" --token "paste-your-token-here"

After the first run you can drop --token — it remembers you:

csq-xp-setup --deal "Acme Corp"

Not sure of the exact deal name? Just run csq-xp-setup on its own to browse every deal in the Disco.

Answer a few quick questions

The tool walks you through a short setup. Everything is pre-filled from the Disco — press Enter to accept, or type something else to change it:

  • Which account to build in (it remembers your last one).
  • Project names — sensible defaults like Client POC [iOS].
  • One App or CSQ XP — for CSQ XP it helps you pick or create a master project and choose an environment.
  • Where to store the data — pick a region.

Then it shows a summary and asks "Create these projects?" — nothing happens until you say yes.

Just want to see what it would do? Add --dry-run to preview the whole plan without creating anything. Perfect for a first look or a screen-share.

4Hand it to the client

When it's done, it prints everything you need to pass along:

  • Links to each project in Console.
  • The right setup docs for the client's framework (iOS, Android, React Native, Flutter…).
  • Copy-paste instructions for the client's developers, e.g. "Implement Contentsquare with datasourceid …".

Drop those into your handoff email or ticket. That's it.
